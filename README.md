# Multiplication Table Generator

## Description
A simple Python program that accepts a number and a specified limit from the user and generates the multiplication table up to that limit.

## Objective
- Practice using `for` loops in Python.
- Learn how to take user input.
- Practice formatted output.
- Understand basic multiplication operations.

## Tools Used
- Python

## How It Works
1. The program asks the user to enter a number.
2. It asks the user to enter the limit.
3. A `for` loop is used to generate the multiplication table.
4. The result is displayed in a clear format.
